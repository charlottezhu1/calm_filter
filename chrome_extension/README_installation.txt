Calm Filter: installation
=========================

1. Download and unzip the folder.
2. Chrome or Edge: go to chrome://extensions (or edge://extensions), turn on "Developer mode" in the upper right corner, click "Load unpacked" and select the chrome_extension folder.
   Firefox (140 or newer): go to about:debugging#/runtime/this-firefox, click "Load Temporary Add-on" and select manifest.json in the folder. It stays until Firefox restarts.
3. Confirm that Calm Filter appears in the list and is enabled.
4. Open x.com or bsky.app. The distribution bar appears under the Post (X) or New post (Bluesky) button, and moves to the bottom-right corner when the window is too narrow.

Click the Calm Filter icon to open the switches (Hide HAN posts, Color post borders, Affect distribution). Changes apply immediately. The same popup has "Export distributions", which saves the counters as PNG or JSON, or copies the JSON.

In the distribution box, The first counter, "My Browsing Affect Distribution", follows you through every feed. "Add" (bottom right) starts up to two more, the pause button stops a counter adding posts, the switcher (above the name) swaps between counters, double-clicking the name renames it, and the cross deletes it right away. Every running counter counts every post you see. If you delete them all, only "Add affect distribution" is left. Counters are saved until you delete them.

After updating the extension files, click the reload icon for Calm Filter on the extensions page and refresh the site.
